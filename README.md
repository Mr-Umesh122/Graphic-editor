# Poster Editor

A simple web-based **Poster Editor** built using **HTML, CSS, and JavaScript**. It allows users to create and customize posters directly in the browser.

## Features

* Add and edit text
* Customize text size and style
* Change colors and backgrounds
* Add images
* Move and resize elements
* Simple and responsive editor interface

## Technologies Used

* HTML5
* CSS3
* JavaScript
